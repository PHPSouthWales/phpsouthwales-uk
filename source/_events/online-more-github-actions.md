This month we have another GitHub Actions talk from Ryan Chandler who is going to build on the talk that he gave for us back in November and look at some of the things that he's been doing recently such as:

- Writing custom actions with PHP & Docker.
- Automatically screenshotting particular pages in your application when a pull request is made.
- Enforcing particular formats for your pull requests, e.g. ensuring the title has a Jira ticket ID or that it contains a certain word based on feature, hotfix, release.
